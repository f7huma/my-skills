# منصة مكتب فيصل حميضان الحميضان للمحاماة والاستشارات القانونية

ترخيص رقم 47529 — منصة داخلية لإدارة القضايا والتنفيذ والمواعيد، وبوابة خاصة للعملاء.

**التقنية:** Laravel 13 · PHP 8.3 · PostgreSQL 17 · Inertia v3 + React 19 + TypeScript · Tailwind 4 · طوابير وجدولة Laravel · mPDF للتقارير العربية · ClamAV محلي · Docker Compose + Caddy (HTTPS).
