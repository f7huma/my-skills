# شروط تفعيل بيانات العملاء الحقيقية

لا تُدخل أي بيانات عميل حقيقية قبل تحقق كل بند وتوثيقه (من نفّذه ومتى):

## الاستضافة ومواضع البيانات
- [ ] تحديد موقع مركز بيانات VPS وتوثيقه، والتحقق من توافقه مع نظام حماية البيانات الشخصية؛ وإن كان خارج المملكة: تقييم لائحة نقل البيانات الشخصية إلى خارج المملكة والضمانات اللازمة.
- [ ] تحديد موقع الوجهة المنفصلة للنسخ وموقع نسخ Hostinger وتوثيقهما.
- [ ] التأكد من عدم استخدام أي خدمة خارجية لمعالجة الملفات (لا تخزين سحابي ولا ذكاء اصطناعي ولا تحليلات).

## التشغيل
- [ ] `docker compose build` ينجح على الخادم، و`docker compose ps` يظهر كل الخدمات سليمة.
- [ ] HTTPS يعمل بشهادة صحيحة على الدومين، وفحص TLS في حالة النظام «سليم».
- [ ] ClamAV يعمل (فحص الماسح «سليم»)، ورفع ملف EICAR التجريبي يُرفض.
- [ ] `php artisan ops:security-check` يمر بلا إخفاق.
- [ ] نسخة احتياطية ناجحة ومتحقق منها ومنسوخة للوجهة المنفصلة.
- [ ] **اختبار استعادة ناجح على بيئة معزولة** (`scripts/restore-test.sh`) مع تجربة دخول وفتح مرفق يدويًا.
- [ ] قناة التنبيه مضبوطة ووصلت رسالة اختبار.

## الأمن
- [ ] مراجعة أمنية لإعداد الإنتاج: ملفات البيئة (`chmod 600`)، SSH بالمفاتيح فقط، الجدار الناري (22/80/443)، تحديثات النظام التلقائية.
- [ ] المفاتيح الثلاثة محفوظة في خزنة المكتب خارج الخادم.
- [ ] المصادقة الثنائية مفعلة لكل محامٍ ورموز الاسترداد محفوظة.
- [ ] نجاح كل وظائف CI بما فيها `ready-to-deploy` على الإصدار المنشور، ومعالجة أي ثغرة عالية أو حرجة.
- [ ] حذف أي بيانات تجريبية من قاعدة الإنتاج (لا حسابات `@example.test`).

## القانون والإجراءات
- [ ] مراجعة قواعد المواعيد (نظام التنفيذ المواد 14 و18 و36 ولائحته) واعتمادها أو إبقاؤها «يحتاج تحديدًا».
- [ ] مراجعة تقويم الإجازات للسنة الحالية والقادمة.
- [ ] ضبط مهلة إعادة كل نوع طلب إجراء وفق شروط الخدمة.
- [ ] مراجعة نصوص البوابة والتقارير الموجهة للعميل.
