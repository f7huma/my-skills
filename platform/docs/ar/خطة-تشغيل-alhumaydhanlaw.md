# خطة التشغيل لموقع alhumaydhanlaw.com — انسخ والصق

هذه الخطة مكتوبة لوضعك بالضبط:
- الدومين: **alhumaydhanlaw.com** (على Hostinger)
- الخادم: **VPS KVM 2** (على Hostinger)
- بيئة التجربة: **https://preview.alhumaydhanlaw.com** (بيانات وهمية فقط)
- المنصة الحقيقية: **https://app.alhumaydhanlaw.com**

كل الأوامر أدناه تُنسخ كما هي دون أي تعديل. المفاتيح وكلمات المرور تُولَّد تلقائيًا على الخادم ولا تُرسل لأحد.

---

## المرحلة 1 — تجهيز الخادم في لوحة Hostinger (مرة واحدة)

1. افتح https://hpanel.hostinger.com
2. من القائمة الجانبية اضغط **VPS** ثم اضغط على خادمك.
3. ابحث عن **Operating System** (نظام التشغيل):
   - إذا كان **Ubuntu 24.04** فانتقل للخطوة 4.
   - إذا كان غيره: اضغط **Change OS** ← اختر **Plain OS** ← **Ubuntu 24.04** ← عيّن كلمة مرور root واحفظها في خزنتك ← أكّد. (الخادم جديد فلا يضيع شيء.)
4. في صفحة **Overview** للخادم انسخ الرقم الظاهر بجانب **IPv4** (شكله أربعة أرقام بينها نقاط). هذا "عنوان الخادم".

## المرحلة 2 — تشغيل أمر التجهيز على الخادم

1. في صفحة الخادم نفسها اضغط زر **Browser terminal** (يفتح شاشة سوداء).
2. الصق هذا السطر ثم اضغط Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/f7huma/my-skills/add-design-skills/platform/scripts/server-bootstrap.sh | bash
```

3. انتظر 5–15 دقيقة حتى تظهر عبارة **✅ اكتمل تجهيز الخادم** ومعها عنوان IP.

## المرحلة 3 — ربط الدومين (سجلات DNS)

1. في hPanel من القائمة الجانبية اضغط **Domains** ← **alhumaydhanlaw.com** ← **DNS / Nameservers**.
2. في قسم **Manage DNS records** أضف سجلًا:
   - **Type:** `A`
   - **Name:** `preview`
   - **Points to:** عنوان الخادم من المرحلة 1
   - **TTL:** اتركه كما هو
   - اضغط **Add Record**.
3. أضف سجلًا ثانيًا بنفس الطريقة لكن **Name:** `app`.
4. لا تحذف ولا تعدّل أي سجل آخر موجود.

## المرحلة 4 — تشغيل بيئة التجربة

1. انتظر 10 دقائق بعد إضافة السجلات.
2. ارجع لشاشة **Browser terminal** والصق:

```bash
bash /opt/humaidan/platform/scripts/setup-preview.sh
```

3. إذا ظهرت رسالة أن الدومين لا يشير إلى الخادم: انتظر 15 دقيقة أخرى والصق الأمر نفسه مرة ثانية.
4. عند النهاية تظهر بيانات الدخول (وتُحفظ أيضًا في الخادم). لعرضها لاحقًا الصق:

```bash
cat /root/humaidan-preview-credentials.txt
```

5. افتح https://preview.alhumaydhanlaw.com:
   - النافذة الأولى: اسم المستخدم `preview` وكلمة المرور الظاهرة في الشاشة.
   - شاشة الدخول: `lawyer@example.test` وكلمة المرور `Demo-Pass-2026`.
6. جرّب المنصة أسبوعًا كاملًا، ولا تُدخل فيها أي بيانات حقيقية.

## المرحلة 5 — صندوق البريد (اختياري)

المنصة تعمل كاملة بلا بريد: رابط دعوة العميل يظهر داخل المنصة مرة واحدة لتنسخه وترسله له بنفسك (واتساب أو رسالة).
- إن طلبت Hostinger شراء باقة بريد: لا تشترِ، وتخطَّ هذه المرحلة، واضغط Enter فقط عند سؤال كلمة مرور no-reply في المرحلة 6.
- إن كان لديك صندوق **no-reply@alhumaydhanlaw.com**: احفظ كلمة مروره لتلصقها في المرحلة 6.

## المرحلة 6 — تشغيل المنصة الحقيقية

1. في **Browser terminal** الصق:

```bash
git clone --branch add-design-skills https://github.com/f7huma/my-skills.git /opt/humaidan-prod
```

2. ثم الصق:

```bash
bash /opt/humaidan-prod/platform/scripts/setup-production.sh
```

3. سيسألك سؤالين:
   - **بريدك الذي ستدخل به**: اكتب بريدك واضغط Enter.
   - **كلمة مرور no-reply**: الصقها واضغط Enter (لن تظهر أثناء الكتابة، هذا طبيعي). إن لم يكن لديك صندوق بريد اضغط Enter فقط.
4. في النهاية يظهر رابط طويل يبدأ بـ `https://app.alhumaydhanlaw.com/invitation/` — انسخه وافتحه في متصفحك، عيّن كلمة المرور، (التحقق الثنائي اختياري: يمكنك تفعيله لاحقًا من صفحة الأمان).
5. اعرض المفاتيح بالأمر التالي، وانسخ الناتج كاملًا إلى خزنة كلمات المرور ونسخة ثانية في مكان منفصل:

```bash
cat /root/humaidan-production-keys.txt
```

6. بعد حفظها في مكانين احذف الملف من الخادم:

```bash
rm /root/humaidan-production-keys.txt
```

ملاحظة: تشغيل المنصة الحقيقية يوقف بيئة التجربة تلقائيًا لأن الخادم واحد.

## إذا ظهر أي خطأ

انسخ آخر 20 سطرًا ظاهرة في الشاشة وأرسلها لي — لكن **احذف منها أي كلمة مرور أو مفتاح** قبل الإرسال. لا ترسل أبدًا محتوى ملفي `humaidan-preview-credentials.txt` أو `humaidan-production-keys.txt`.
