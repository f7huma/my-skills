# التشغيل المحلي

## المتطلبات
- PHP 8.3 مع الامتدادات: pdo_pgsql, intl, zip, gd, sodium, fileinfo
- Composer 2، Node.js 22، PostgreSQL 16 أو 17
- أدوات `pg_dump` و`pg_restore` و`createdb` (لاختبارات النسخ الاحتياطي)
- اختياري: ClamAV (`clamd`) للفحص الحقيقي محليًا؛ وإلا استخدم المحرك التجريبي `fake`

## الخطوات
```bash
cd platform
composer install
npm ci
cp .env.example .env
php artisan key:generate
```
عدّل `.env`: بيانات قاعدة البيانات، و`APP_DEBUG=true` و`SCANNER_DRIVER=fake` للتطوير فقط، ثم ولّد مفتاحي التشفير:
```bash
php artisan files:generate-key           # ضعه في FILES_ENCRYPTION_KEY
php artisan files:generate-key --backup  # ضعه في BACKUP_ENCRYPTION_KEY
```
```bash
createdb humaidan_dev && createdb humaidan_test
php artisan migrate --seed      # بيانات اصطناعية فقط
npm run build                   # أو npm run dev أثناء التطوير
php artisan serve
php artisan queue:work --queue=scans,default   # عامل الطوابير (فحص المرفقات)
php artisan schedule:work                       # الجدولة
```

## الاختبارات
```bash
php artisan test                        # PHPUnit على قاعدة humaidan_test
npx tsc --noEmit -p tsconfig.json       # فحص أنواع الواجهة
# المسارات الكاملة في المتصفح:
php artisan migrate:fresh --seed && php artisan serve & php artisan queue:work &
BASE_URL=http://127.0.0.1:8000 node tests/e2e/flows.cjs
```
ملاحظة: أعد تشغيل `queue:work` بعد `migrate:fresh` لأن الجداول تُحذف تحته.
